## 목표와 범위

개인 MVP에서 기능 하나를 확장한다. 예시는 시장 보고서의 최소 거래량 필터다. 새 UI나 외부 API 없이 함수 계약과 테스트에 집중한다. 시장 예제를 사용하면 11주차 `korea_market_mvp`를 개인 저장소에 복사하고, 먼저 기존 테스트 12개를 통과시킨다.

## 예시 계약: 최소 거래량 필터

- `analyze(quotes, market, min_volume=0)`로 확장한다.
- min_volume은 0 이상의 int이고 bool·문자열·실수는 ValueError로 거절한다.
- 거래량이 기준 이상인 종목만 남긴다. 기존 시장 필터와 동시에 적용한다.
- 중복 코드·혼합 날짜는 필터로 가려지더라도 전체 입력에서 거절한다.
- 모든 결과가 제외되면 기존 빈 결과 계약(count=0, mean=None)을 유지한다.
- 기존 입력 목록과 행을 변경하지 않고 기존 정렬 규칙을 유지한다.
- 이번 필수 범위는 함수와 테스트다. CLI 옵션 추가는 선택이며 추가하면 도움말·오류·종료 코드도 검증한다.
